# Bombora Smart Search

Modul **Bombora Manageru** – live vyhledávání produktů pro WooCommerce (fuzzy, WPML, doporučení).

## Vydání nové verze
1. Zvyš `Version:` v `bombora-smart-search.php` a `ZGSS_VERSION` (musí se shodovat).
2. Přidej sekci `## [X.Y.Z]` do `CHANGELOG.md`.
3. Push do `main` → GitHub Action sestaví `bombora-smart-search.zip` + `.sha256` a vytvoří Release `vX.Y.Z`.
4. Weby s Bombora Managerem nabídnou aktualizaci v Pluginy / Bombora → Modules.
